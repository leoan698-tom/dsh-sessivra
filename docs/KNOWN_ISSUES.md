# 已知问题

## dev.24 受管任务

- 任务记录、问题/裁决、自动通知与安全边界已实现。初始隔离 Host 验收见 `artifacts/managed-tasks-dev24/RESULT.md`；后续当前桌面的 A/B/C 四任务闭环在 local.1 上通过，修复与续验记录见 `artifacts/managed-tasks-dev24/desktop-native/RESULT.md`。隔离 Host、真实桌面模型和自动化回归分别报告，不代表任意模型的可靠性统计。
- AI 仍需把自然语言需求映射到任务工具和字段。已知前置问题应写入 `requiredQuestions`；插件不从任意自然语言自动推断所有依赖，也不能保证任意模型始终正确使用工具。
- 业务问题按同一 scope、topic、context、options 去重；不同 topic 的等价问题可显式合并。未登记到协议中的聊天问句不能保证去重。
- 原生工具审批保留宿主入口；这里的业务裁决不授予命令、账号或文件权限。
- 暂停/取消等待当前工具结束；正在长时间等待外部操作的工具不会被强杀。直接人工输入到执行会话会暂停并保留原任务，随后须按输入意图更新或继续。
- 重启保留记录，但不会在启动时自动唤醒模型。不确定投递先回查；未能确认外部效果时不自动重试。资源声明只协调采用协议的任务，不是文件锁或 ACL。
- 当前持久域上限为 256 个任务、512 个问题、4096 个事件。达到上限返回 `TASK_STORAGE_LIMIT`，不自动删除历史；本版还没有历史任务归档工具。每项任务保留最近 64 条变更、问题保留最近 32 条旧决定，详细对话仍属宿主历史。

## DSH rc.5 的 Zod 兼容约束

当前插件使用 Zod 4.4.3，与 DSH 0.2.1-rc.5 的 storage-domain、Typert 和子智能体类型保持一致。该版本受 [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5) 影响：超大集合校验可能消耗过多内存，官方公告列为高危，4.6.6 起修复。

发布准备中尝试将插件单独升级到 4.6.7；TypeScript 检查确认其 schema 内部类型与宿主固定的 4.4.3 不兼容，storage-domain 的 get/set 类型也无法成立，因此没有发布该升级。未强制覆盖宿主依赖，也未用类型断言隐藏冲突。这个风险尚未关闭，需要随兼容的宿主版本升级并重验。

插件现有参数长度、队列、时效及权限检查继续有效，但不能据此宣称依赖缺陷已修复。发布验证通过不代表依赖无漏洞；本版保持预发布状态。

## 功能验证边界

- 宿主固定为 0.2.1-rc.5，子智能体派任务使用 internal 接口，其他版本需要适配。
- 原生侧栏的子节点容器依赖 rc.5 的稳定行标识；宿主升级后须重新核对或迁移到正式子内容插槽。无法匹配行时保留原生列表。侧栏搜索与归档筛选沿用宿主范围；子智能体上下文引用继续使用原生 `@`。
- 隔离运行时的确定性模型检查不代表任意真实模型都能正确理解自然语言通信意图。
- 原生引用每条消息最多 3 个会话，历史快照可能截断。
- 不支持跨机器/进程；消息送达、领取及空闲状态不代表业务任务完成。
