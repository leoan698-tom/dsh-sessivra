# 测试报告

## 0.3.0-dev.16 发布验证

本版功能和持久 schema 沿用 dev.15。发布整理增加仓库编译产物、准确安装命令、公开文档及可独立运行的测试夹具。

`npm run check` 执行 lint、TypeScript、构建、单元/客户端与 rc.5 隔离宿主集成检查。本轮 Windows 检查通过：单元及客户端 34/34、集成 59/59，lint、TypeScript 和构建均通过。其中 3 项 Windows 文件锁测试在 Linux 按平台跳过。默认检查不再依赖本机旧 rc.3 验收缓存；旧 support 脚本及原始证据保留在本地，不计入本版通过数。

全新克隆的依赖安装及编译产物一致性由该标签的 GitHub Actions 检查。Git 标签/Release tarball 的命令安装、profile 注册和安装版运行时检查，单独记录在 GitHub Release 验证说明中。

## dev.15 的已有验证范围

单元及客户端 34/34、集成 59/59、已安装插件的引用通信复验 6/6 分别通过；安装复验是同类功能在安装版上的重复检查，不与 93 项相加。桌面检查覆盖原生会话搜索、唯一引用候选、无“发送至”前缀的标签以及文件/目录入口保留，没有提交真实业务任务。

核心隔离场景包括：冷会话上下文进入当前模型、目标不唤醒；多引用准确发送；快照中的第三方链接不能创建收件目标；团队内外子智能体恢复原对象并关联回信；一次性及他人子智能体只读；引用恢复、修订校验、撤权和消息去重。

模型输出来自确定性免费适配器。这些检查证明真实宿主的引用、传输、归属和持久化链路，不证明真实模型在任意业务请求中都能稳定理解用户意图。原始桌面记录含用户环境信息，仅留在本地。当前发布保持预发布状态，未宣称完成新版完整真实模型业务验收。
