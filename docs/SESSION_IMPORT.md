# 导入 Claude Code / Codex 会话

适用于 Sessivra 0.3.0-dev.29。

打开侧栏「导入会话」，选择 Codex 或 Claude Code 即可加载会话。搜索项目名或会话标题，勾选记录后点击「导入所选会话」，再点「打开并继续」。搜索覆盖已加载的会话，可继续加载较早的记录。Windows 上能读到标题但缺少本机原档的 Claude Code 桌面会话会明确标记。

会话保存在其他位置时，可先选择来源，再点「选择文件夹」。支持工具的数据根目录、包含原档的文件夹，以及 SessionBridge 的 Data 目录。返回导入页会复用本次运行已加载的列表，点击「刷新」可读取最新记录。

默认识别 Claude Code 的项目记忆，以及 Codex 按会话 ID 匹配的记忆摘要。勾选「同时导入全局记忆」时，新导入的会话还会保存该来源的用户级记忆。续聊优先使用原工作目录。原工作树已删除时，能唯一确认本机项目根目录就归入该项目，否则使用 DSH 默认工作目录。

Claude Code 支持 `.jsonl`，Codex 同时支持 `.jsonl` 和 `.jsonl.zst`，压缩原档可以直接选用。每个来源会话保存一次快照。同一个 Codex 会话的两种格式复用同一 DSH 会话。原始文件和记忆文件可以从导入结果下载，也可以从会话菜单选择「查看导入原档」。续聊使用最近 12 万字符的用户和助手正文、最多 2.4 万字符的选定记忆，以及 DSH 当前模型和工具设置。完整的工具记录和附件引用保存在原档中。导入时没有模型请求。

每批最多 20 个会话，单个原档及解压后的记录各有 64 MiB 上限，每个会话的记忆文件合计上限 4 MiB。

选择 Claude Code 主会话会同时导入其子会话，保留父子关系。导入后的会话可以在工作区搜索正文并定位到原消息，也可以在输入框用 `@` 按标题引用；同一条消息可以引用多个会话。正文索引保存在当前 DSH profile，重启后复用。
