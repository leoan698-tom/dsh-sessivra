# dev.26 发布验证

2026-11-04（America/Los_Angeles）。`0.3.0-dev.26` 的运行时代码来自当前桌面安装实测的 `0.3.0-dev.26.local.14`；公开分发沿用 `dsh-plugin-sessivra` 包名和 `latest` 标签。兼容 DSH 0.2.1-rc.5 / Node.js 24+。

## 本次功能与桌面验证

- 拖动侧栏会话到任意视图上下左右边缘，蓝色边框提示拆分位置，支持横纵嵌套、重新停靠与分隔线调宽。
- 各视图使用准确会话上下文和独立输入框；标题栏压为 40px 单行，“对话、轨迹”移入标题旁菜单，侧栏同步高亮正在展示的会话。
- 主视图、附加视图均使用 × 关闭。主视图关闭后提升剩余视图，先卸载原编辑器 occurrence 再导航，保持会话引用和草稿；最后一个视图关闭后返回原生新会话入口，不归档历史、不停止任务。
- 拖进输入框插入原生会话引用，保留已有文字和引用，松手不自动发送。

桌面实际验证菜单切换、B 切到轨迹而 C 保留对话、附加视图关闭局部合并、主视图关闭后的草稿保留与可编辑、最后视图关闭及调宽。早期自由分屏也已在三个普通会话验证独立的真实模型发送与回复。标题栏及关闭修复的最终复测只使用未发送草稿，没有新增模型请求。

原始截图、配置和会话日志保留在本地，不随公开包上传。公开摘要不含会话 ID、个人配置或本机工作路径：[机器可读验证摘要](dev26-evidence.json)。

## 安装和边界

在 DSH「插件 → 添加插件」中输入 `dsh-plugin-sessivra@0.3.0-dev.26`，或按[官方 CLI 安装说明](../NPM_PUBLISH.md)操作。DSH 自带 pnpm 的发布时间保护可能让裸包名暂时选中旧版，发布首日应指定准确版本；不需修改全局保护。

布局只在当前插件运行期间保留，刷新后重建；不支持拖出独立操作系统窗口。原生内容、标题和侧栏扩展依赖 rc.5 的 DOM 与插槽协议，宿主升级后需要重新核对。[既有已知问题](../KNOWN_ISSUES.md)仍适用。

公开状态以 [npm registry](https://registry.npmjs.org/dsh-plugin-sessivra/latest) 和 [GitHub Release](https://github.com/leoan698-tom/dsh-sessivra/releases/tag/v0.3.0-dev.26) 为准。
