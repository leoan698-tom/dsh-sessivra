# dev.27 任务中心发布记录

`dsh-plugin-sessivra@0.3.0-dev.27` 将桌面验证过的 `0.3.0-dev.27.local.14` 提升为公开开发版。支持 DSH `0.2.1-rc.5` 和 `0.2.2-rc.1`，需要 Node.js 24 或更高版本。

- 在 DSH 0.2.2-rc.1 的实际桌面中，从「任务中心 → 历史」打开已归档的采购任务。详情顶部显示总价 68.90 元、总数量 9 件、用户已验收及验收时间。
- 点开 Markdown 报告后，五列表格直接显示三项小计 3750、1640、1500 分。展开阅读、切换原文再返回预览，均能回到同一份报告。复核后持久归档与原快照一致。
- 在 DSH 0.2.1-rc.5 的 Gateway 上验证了创建任务、回答两个任务的共同问题、查看交付文件、退回、再次提交、人工验收、归档及历史回查。

在 DSH「插件 → 添加插件」选择 npm 官方源，输入 `dsh-plugin-sessivra@0.3.0-dev.27`。安装后从侧栏打开「任务中心」。操作步骤见[受管任务](../MANAGED_TASKS.md)。
