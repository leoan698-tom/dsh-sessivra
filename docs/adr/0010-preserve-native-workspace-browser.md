# 保留原生工作区栏，只扩展会话行

2026-11-01，用户提供未安装插件时的侧栏截图，要求安装后保持「工作区」这一行不变。此前插件以高优先级替换整个 `sidebar.workspaces`，连同宿主标题、搜索、视图选项、添加工作区及目录嵌套一起替换，超出会话树展示所需范围。

从 dev.17 起不再占用 `sidebar.workspaces`。原生 WorkspaceBrowser 始终负责标题栏、原生搜索、视图配置、工作区管理、目录分组和原生会话行。插件通过正式 `sidebar.workspaces.session.row.action` 插槽取得行身份，仅在该会话下方展示真实子关系。删除「工作区管理」及「更多 → 会话树」切换入口。

rc.5 尚无行子内容插槽，因此展示层使用受限 DOM 桥：从自身插槽节点定位宿主 `data-row-key="session:<id>"`，挂载一个由插件拥有的相邻容器，并将展开按钮放入对应原生行。只观察该行所在列表的子节点移动，不读取生成 CSS 类，不重写宿主事件或数据 store。原生行移动时子内容跟随；行或插件卸载时清除容器、按钮和隐藏标记。宿主结构不符合已核对的 rc.5 约定时不插入，保留原生列表。

普通子会话已有原生行时，仅在其可见祖先已挂载的情况下隐藏重复原生行，在祖先树中显示；祖先工作区折叠或移除后恢复独立可见行。原生归档与搜索展示范围继续由宿主管理；树的发现与消息权限仍遵循 ADR-0008、ADR-0009。所有行共用一个不重叠的 2 秒只读刷新，无行订阅时停止。

会话行有子节点时，通过插件拥有的布局标记给展开按钮预留独立位置，使用宿主 `--dsh-workspace-indent` 保持工作区缩进；子树显示分支连接线。按钮事件仅负责展开收起，防止点击、双击和拖动传给宿主会话行。无子节点或卸载时删除布局标记，恢复原生间距。

本变更不改变通信、上下文引用、持久关系及权限。DOM 桥与 rc.5 明确绑定；升级宿主须重新核对其行结构，未来有正式行子内容插槽时迁移到该接口。

2026-11-02 补充：子节点高亮读取宿主全局 `useSessions` 的 `retainedBy.mainView`，打开其他面板时清除，不能把最后一次点击作为当前选择。定位到子会话时展开必要祖先并滚入视野；折叠偏好按会话 ID 存入客户端本地存储，默认展示前两层子节点，更深分支默认收起。每次轮询不覆盖用户主动折叠。

普通子会话提供重命名、置顶/取消置顶和归档菜单，调用 `sessions.using(... workspaceOperation ...)` 与 `uiWorkspace`，不直接写会话文件。归档先确认，不传 `stopActivity`，保留宿主运行状态保护。队员不套用普通会话管理菜单。队员名称优先使用已有任务说明，原名和完整文本保留在提示中；等待批准、方案确认和回答来自宿主状态，空闲不推断为完成。

列表仅显示一处加载或错误信息，首次失败、空结果和折叠状态都能区分；重试失败保留上次成功结果。搜索仍由原生 WorkspaceBrowser 负责，返回列表后由当前会话身份恢复树中定位。

2026-11-02 第二轮用户走查修复：用户明确要求逐项解决队员搜索、显示名称、父会话导航、折叠标记及窄栏问题。队员可设置本机显示名称，按真实会话 ID 存储；不改 Team 名册、不猜测历史提示词中的职责。普通子会话重命名采用宿主相同的输入框样式与焦点/输入法行为，使用共享 Button 和 Modal footer。

本轮扩展此前“搜索完全由原生负责”的展示边界：保留原生搜索框、原生结果和工作区浏览器，在同一滚动区追加可见队员结果。rc.5 没有搜索结果扩展插槽，因此在 shell.overlay 挂载受限桥接组件，按已核对的中英文输入占位文案、结果树 aria-label 及层级定位；不读取生成 CSS 类、不修改宿主 store 或事件。只在补充结果/加载/错误存在时隐藏原生“无匹配会话”，退出搜索或卸载后清除标记和自有容器。搜索打开使用准确父子地址，清除原生搜索后按真实 Workspace 身份展开必要分组和分支；定位观察最长 5 秒，完成、用户继续操作或插件卸载即结束。升级宿主需要重验这一边界。

父会话可用性使用 Host SessionSummary.agentAvailable 的明确布尔值，缺失不推断离线；可继续队员在父会话不可用且自身未运行时显示相应提示。只读 composer 扩展使用宿主相同选择条件，仅添加打开准确父会话的操作，不自动发送或自动返回。普通单次、未知模式及运行中子智能体仍由宿主处理。收起包含当前会话的分支时保留轻量标记，不重复强制展开；叶子占位压至 4px，菜单在悬停/键盘聚焦/打开时显示，长名称保留末尾六个字符。

2026-11-02 第三轮补充：队员搜索通过公开 Slot 注册项订阅原生 WorkspaceBrowser 已有的共享视图 store，只读 `archivedFilter`，不另建筛选状态、不调用宿主 store actions。“仅已归档”时不追加未归档队员；筛选状态不可识别时同样保留原生结果。Host 归档集合变化立即排除队员及其已归档祖先的分支，不等待树轮询。当前树发现本身不含已归档队员，不因此扩展发现或恢复权限。

队员标识与运行、等待、只读、创建中等状态并列显示，不相互替换。子会话菜单保留 React portal 的宿主行祖先关系，在插件自己的子树与操作区捕获并隔离 pointer-over/out。重命名、队员显示名、归档确认及错误弹窗统一通过 shell.overlay 的独立展示组件渲染，彻底脱离宿主会话行的 React 事件祖先链；仅靠 body portal 和事件阻止不足以保证实际桌面中不残留父行 HoverCard。弹窗请求由发起行拥有，关闭、行卸载或插件卸载时清除；表单与操作仍由原组件负责。原生 pointer-down/click 捕获继续关闭已打开卡片，正常父行悬停与弹窗焦点恢复保持不变。
