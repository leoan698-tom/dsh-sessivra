# 新建智能体自动进入真实主子树

后续决策：[ADR-0014](0014-sidebar-conversations-and-teammates-only.md) 依据用户确认，将侧栏展示缩减为普通会话、普通子会话和团队队员。下文的全量子智能体展示要求保留为历史；自动发现、只读观察及通信资格规则继续有效。

dev.15 的 [ADR-0009](0009-unified-session-references-and-messaging.md) 进一步统一 @ 上下文引用和通信入口。下文发送候选限制对应实际发送资格，不再限制可见的上下文引用候选。

2026-11-01，用户明确「新建智能体应自动入树，避免漏显示」。这替代 ADR-0006 对展示层仅限主会话直接 continuable 子智能体的限制；ADR-0007 对实际消息权限的要求不扩大。

发现合并宿主可见 Session 列表、父节点 subagentCatalog 和 Team 名册。以已知普通会话为根，逐层遍历本地真实 parentSession 关系。目录中的外部执行、名册创建中/失败、暂未列出的本地子会话保留状态节点；真实 Session 头与目录冲突时以头为准，不改挂、不伪造身份。循环、归档、不可见父关系不穿透到其他根。

展示不等于可打开或可收件。有效 one-shot 描述符打开只读历史，continuable 打开原会话；未知描述符、无本地历史的目录记录展示明确状态。发送候选仅选取直接属于普通来源会话、有效 continuable、无 Team 归属故障、队员 phase=active 的对象。发送仍由 transport 重新验证。

一次刷新对每个可达会话最多获取一次可释放观察，不解析正文来推断名字或关系；单节点观察失败只使该节点暂不可打开，不能中断其他节点发现。客户端保持 2 秒轮询并禁止重叠请求，新记录无需重新打开树或修改名单即可出现。显示和导航不发送消息，不激活模型，不改变会话或团队存储。
