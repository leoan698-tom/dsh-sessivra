# 持久任务状态、问题与裁决、自动通信和安全调度构成任务级协作

2026-11-03（America/Los_Angeles），用户要求把主子会话的任务状态同步、问题和裁决去重、自动通信、安全调度一起实现并验证完整流程。此要求扩展 ADR-0002/0003 的消息通信范围，并落实 ADR-0011 中任务独立于会话的身份。原有单次消息与有界进展查询保持其含义；它们不自动升级成任务验收。

## 任务身份与授权

受管任务具有稳定 requestId 派生的任务 ID、协调会话、执行会话、明确目标与验收条件、工作目录、原配对许可时间、任务版本与已采用版本、裁决版本、检查点和验收证据。受管任务可以发给普通会话，也可以发给主会话直接拥有的 continuable 原生子智能体；后者保留宿主的归属与生命期。普通子会话仍能独立打开和接受直接用户输入。

创建受管子会话用 session_task_create_child；已有对象用 session_task_assign。新参与对象仍须通过准确原生引用/已选收件对象取得许可。已加入同一 scope 的准确对象可继续接收范围内任务，不要求重新 @ 或手工复制提示词。引用本身不创建任务，子会话不能借共享问题向其他会话派活。许可撤销、目录变化、归档或原生子归属变化会阻断访问和投递；重复创建不会复活撤销的许可。

## 状态与执行边界

独立持久域 dsh_sessivra_tasks 保存任务、问题和出站事件，不改写三个旧持久域。单写入队列串行处理状态变更、宿主事件与持久提交；消息投递先持久预留，投递不确定时隔离并回查真实 inbox/transcript，不自动重发。

一个执行会话同一时刻只有一个受管任务占用执行位置。暂停、等待裁决和等待验收都不会把位置让给下一项任务。声明的文件资源含目录重叠检查，只协调参与此协议的任务，不是文件系统 ACL。前置 requiredQuestions 可在任务创建时登记，未裁决前不会启动执行会话；运行中新发现的问题自动回传并结束当前模型回合。回答从最近安全步骤恢复同一任务，不排到等待该答案的任务后面。

现有工具执行不中断。任务调整在后续模型/工具边界校验最新版本，执行者须显式报告已采用的版本；旧版本结果被拒绝。暂停/取消等当前工具完成后生效，并保留已有检查点及外部副作用。模型空闲而未提交结果时记录为受阻，保留未完成义务，不解释为完成。插件重开不主动调用模型；恢复未知运行须显式继续原任务，不能凭步骤编号重做外部写入。

## 问题与裁决

同一 scope 内，规范化 topic、适用 context 与一致 options 对应同一个问题。措辞不同可以复用同一个键；协调者可显式合并适用条件和选项相同、裁决不冲突的不同键。合并别名持久化。相似但适用条件不同的问题不自动合并。

业务裁决与宿主权限批准完全分开。协调者只能在用户已授权范围内记录实施决定；需要用户选择时只请求一次集中呈现。用户决定要求绑定真实当前用户消息 ID 和原文摘录，已升级给用户的问题还要求呈现之后的新输入；协调者决定不能覆盖用户决定。用户直接在执行会话答复其待决问题时，插件验证来源后向协调会话和有关任务同步。旧裁决保留版本历史；验收后发生裁决变化会标注原验收版本并通知协调者检查影响。

直接人工输入到执行会话会保护性暂停原受管任务并推进版本，避免协调者的旧视图覆盖用户调整。模型按输入意图更新同一任务、记录问题答复或继续原任务；无关聊天保留暂停记录，不丢弃原工作。

## 模型与界面

正式 systemPrompt.context 在每轮准备时提供有界当前任务摘要；工具接口和执行前检查实现版本与状态约束。摘要属于任务数据，不能授予新的工具权限。普通进展写入状态而不唤醒主会话，问题、阻塞与结果使用持久事件通知。会话树显示待裁决、待接手、执行、待同步、待验收等状态及版本提示，宿主原生权限提示优先显示。

最终结果先进入待验收。协调者检查具体产物并记录证据后，才把任务标记完成并放行队列。插件验证验收记录的角色与版本，但不能独立证明任意业务结果正确。原生权限交互仍由宿主管理。模型没有把业务前置条件映射到结构字段时，插件不能从任意自然语言推断全部隐含依赖。
