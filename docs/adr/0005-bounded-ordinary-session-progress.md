# 普通会话进展是有界只读证据，不是共享历史或任务验收

按用户本轮明确的范围，在普通会话通信上增加只读进展查询。只使用准确会话 ID 与已经成立的通信许可；查询不授予许可、不激活目标、不发送或确认消息。返回采样时间、有限事件、该对会话的关联请求/回复、增量游标及覆盖范围，不暴露原始请求头、工具参数/输出、推理正文或全部历史。这样协调会话能够观察建设和复核会话，又不把普通通信扩大成任意历史读取或共享任务板。

宿主没有提供本次可核查的待用户交互快照时，等待用户状态必须为未知；空闲、投递、领取、显式确认及一轮结束均不等于业务完成。冷会话读取允许正式 Query 内部准备/回放日志，必须标明这个资源边界，不能声称宿主只读取了返回的几十条事件。过旧游标跳过的范围明确返回，不能宣称完整增量。

关联回复结束原请求的回复链。它不再给协调者增加“必须回复这条回复”的义务，以免阻断将建设结果提交独立复核；未回复的入站请求仍受原防回环约束。创建请求以父会话 ID 和稳定 requestId 绑定准确子会话，重试复用同一 ID 和初始消息；部分失败返回可恢复状态，不以相同标题自动新建替代会话。
