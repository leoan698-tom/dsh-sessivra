# 原生 @会话统一承担上下文引用和按意图通信

2026-11-01，用户要求「把发送至删除，后续所有的@会话不止是可以通信，也可以作为上下文引入」。本决策取代 ADR-0003、ADR-0007 中独立发送候选，以及早期“原生引用不能成为通信对象”的产品限制。ADR-0007 的真实父子所有权和传输校验继续适用。

客户端保留宿主原生 reference source 作为唯一可见 @ 会话入口，不替换或修改宿主注册对象，文件/目录引用继续由宿主负责。移除插件“发送至”“发送到”分组。仅保留没有候选的旧 source codec，使持久草稿中的 dsh-message-target 芯片可在提交/复制时转换成 dsh-session。

原生 SessionReferenceResolver 负责在提交时读取准确普通或子智能体会话，生成受预算限制的低信任历史快照。引用、浏览和目标查询不调用消息选择/许可变更、不激活目标、不发送。多个引用均作为上下文；沿用宿主 rc.5 每条消息最多 3 个引用的限制。

模型在当前用户明确要求通信时，先调用 session_message_selected_target。对象由已接受的 session-reference 消息元数据确定，不从快照正文、工具输出或会话标题推断。多引用需传准确 target；省略时返回候选集合，不自动取第一项或最后一项。该查询只读，不产生新配对许可。

实际 session_message_send 校验目标、引用身份和 selectionRevision，随后复用原有选择、许可和消息传输路径。稳定引用修订保存在既有 revision 字符串中，无新增存储字段；同一引用重复发送不能恢复已撤销的许可。重复消息 ID 仍由核心账本处理，不重复投递。归档、不可用、一次性、非当前主会话直接拥有的子智能体不能通过本插件派任务，但宿主允许读取的对象仍可作为上下文。

原生引用元数据属于当前模型可见的历史，插件重开可恢复；若宿主压缩已移除引用元数据，不能从摘要文本伪造引用，应重新 @ 对象。已完成明确发送的持久收件记录仍按原有规则保留。历史 raw dsh-message-target 文本和原有 owner RPC 保留兼容。
