# 侧栏仅展示普通会话、普通子会话和团队队员

用户针对侧栏中大量重复、多层、只读子智能体记录，明确确认：「保留普通会话、普通子会话和团队队员，其他子智能体全部隐藏。」本决策替代 ADR-0008 的全量子智能体侧栏展示范围，并保留其发现、真实身份与只读观察规则。

侧栏保留普通会话及普通子会话的明确父子关系；子智能体仅保留真实 Team 名册确认的队员。队员的创建中、失败、只读及暂不可打开状态继续按原有信息显示，不以状态或标题推断队员身份。

团队外子智能体、一次性执行节点、外部执行节点及团队归属未知的子智能体均不进入侧栏。筛选发生在客户端侧栏构树前，隐藏分支下的子智能体不提升为顶层节点，也不改挂至其他可见父节点。队员之间的真实多级关系继续显示。普通会话仍保留独立可见性。

只有隐藏子智能体的父会话不显示展开箭头或预留展开空位。宿主若提供对应原生会话行，也在本插件挂载期间隐藏；父节点移除或刷新失败不使其重新出现在顶层。真实名册变化后在下一次成功刷新更新显示，卸载时清除插件的隐藏和布局标记。

本次仅缩减侧栏展示。服务端发现结果、持久记录、执行生命周期、原生上下文引用、准确父子导航地址及消息资格不改变；不删除历史，不增加「显示全部子智能体」开关。
