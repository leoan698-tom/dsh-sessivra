# Sessivra 主子会话任务协作

当前公开预发布包：`dsh-plugin-sessivra-0.3.0-dev.25.tgz`。兼容 **DSH 0.2.1-rc.5 / Node.js 24+**。包内包含编译后的服务端与客户端；使用者无需构建。npm 包名为 `dsh-plugin-sessivra`。

local.1 修复未开始任务的待办版本同步及后续任务计数；local.2 修复用户新答复首个模型请求中的当前消息 ID。现有任务、会话和决定保留。dev.25 包含这三处修复。桌面验收摘要及发布核验见[验证记录](validation/dev25-release.md)，原始本地日志不随包发布。

## 在主会话里使用

创建普通子会话并委派实际工作：

```text
创建两个普通子会话：建设 B 实现登录页，复核 C 在建设完成后检查验收条件。
由你协调任务、进度、共同问题和结果，问题集中在这里问我，完成后检查实际产物再验收。
```

也可以通过原生 `@` 选中已有普通会话，明确说“把这项工作交给它，管理进展、问题和验收”。仅引用上下文不会派发任务。

修改正在进行的同一任务：

```text
把 B 当前任务的验证码有效期改为 5 分钟，保留原目标和未完成事项，当前工具完成后采用。
```

安排后续任务：

```text
现在为同一个 B 登记后续任务：补充测试说明。先排队，等当前任务完成并验收后再执行。
```

主会话和子会话每轮收到当前任务摘要。要求已更新、子会话尚未确认采用时显示“待同步”，例如当前 v2 / 已采用 v1。新任务不会因子会话问问题或暂时空闲而提前执行。普通进展只更新记录；问题、阻塞和结果自动通知协调者。

等价业务问题共享一条问题及裁决，条件是协作范围、主题、适用条件和选项一致。不同主题键可由主会话核对后合并。已经回答的问题不会要求用户重复回答；条件变化时要登记新的适用条件或更新裁决。宿主命令权限审批仍在原有入口完成。

结果先进入“待验收”。主会话必须读取产物、检查验收条件并记录证据，之后任务才显示“已完成”。插件校验角色和版本，但不能代替实际业务检查。

## 安装与升级

在 DSH「插件 → 添加插件」中选择 npm 官方源，输入 `dsh-plugin-sessivra@0.3.0-dev.25`；已有同名包按宿主升级入口更新，或使用下方固定版本终端命令。

先正常退出使用目标 profile 的 DSH，备份该 profile 的配置、插件包和存储。然后在 PowerShell 执行（CLI 路径按实际安装位置调整）：

```powershell
& 'D:\DeepSeekHarness\resources\runtime\cli\bin\dsh.cmd' --version
& 'D:\DeepSeekHarness\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add 'dsh-plugin-sessivra@0.3.0-dev.25'
```

CLI 必须显示 `0.2.1-rc.5`。自定义 `DSH_HOME`、profile 要与实际宿主一致。Web 用户换为 `--profile web`。重启后确认插件名 `DSH Sessivra`、版本 `0.3.0-dev.25`、已启用，然后在新一轮主会话输入协作要求。这个完整命令用于终端，不能粘贴到只接受 npm 包名的界面输入框。

安装更新需在 DSH 退出后执行，避免运行中的宿主与包文件版本不同。不要同时启用原信使包、旧 scoped Sessivra 包与当前包；这些包注册同一服务。

## 恢复、回退与卸载

任务状态在独立 `dsh_sessivra_tasks` storage-domain 中持久化。升级没有重写三个旧 Messenger 持久域。重开后可以查看原任务、决定、检查点和结果；启动和查询不会自动唤醒模型。未完成且执行状态未知的任务显示受阻，主会话在核查已完成工作及副作用后继续同一任务。

投递不确定时使用任务回查，保留原 taskId/requestId；不能重建子会话或换 ID 再发一次。插件只在真实 inbox/历史里找到证据后确认投递。冷会话需要先打开该现有会话，再回查；仍无法确认时保留阻塞。

直接在子会话输入会暂停并保留原任务。如果回答现有问题，模型会将真实用户消息绑定到裁决并同步；如果修改同一任务，更新同一记录；如果是无关聊天，原任务继续保留为暂停。主会话基于旧版本的修改会失败并要求读取新状态。

回退时先结束或暂停受管任务，正常退出 DSH，再安装保存的旧包（如公开 dev.20）。旧版本不会读取新增任务域，旧消息和会话树域保留；旧版本不能继续 dev.24 的任务协议。回退不撤销已经产生的外部操作或历史消息。保留新域备份，再装 dev.25 可读取原记录。

卸载用 `dsh plugin --profile desktop remove dsh-plugin-sessivra`。卸载包不主动删除任务域或宿主历史。不要删除整个 profile。
